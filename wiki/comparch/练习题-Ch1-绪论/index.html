练习题 · Ch1 绪论

题型：Amdahl 定律、CPU 性能公式、MIPS 对比、概念辨析
对应笔记：Ch1-绪论

题型概览

题型 核心公式 重要程度
Amdahl 定律（正算 / 反求 / 上限） $Speedup = \dfrac{1}{(1-F)+F/S}$，$Speedup_{max}=\dfrac{1}{1-F}$ ⭐⭐⭐ 高频

一、计算题（Amdahl + 性能公式）

题 1：Amdahl 定律正算加速比（硬件乘法器优化） ⭐⭐⭐

题目：某程序在某机器上运行耗时 100 秒，其中浮点乘法占 60% 的时间。若用硬件乘法器替换原来的软件乘法子程序，使乘法部分加速到原来的 50 倍（S=50），其余部分不变。求：
（1）优化后的执行时间；
（2）整机加速比；
（3）乘法部分在优化后占总执行时间的比例。

考点：Amdahl 定律 $Speedup=\dfrac{1}{(1-F)+F/S}$，及性能递减原则。

解答：

  1. 确定参数：可改进比例 $F=0.6$，该部分加速比 $S=50$。
  2. 新执行时间：
    $$T_{new}=100\times\left[(1-0.6)+\frac{0.6}{50}\right]=100\times(0.4+0.012)=100\times 0.412=41.2\ \text{秒}$$
  3. 整机加速比：
    $$Speedup=\frac{100}{41.2}\approx 2.43$$
    （或直接代入公式：$Speedup=\dfrac{1}{0.4+0.012}=\dfrac{1}{0.412}\approx 2.43$）
  4. 优化后乘法部分耗时 $=100\times\frac{0.6}{50}=1.2$ 秒，占比：
    $$\frac{1.2}{41.2}\approx 2.9%$$

要点/易错：加速比上限由串行部分 $1-F=0.4$ 决定，即 $Speedup_{max}=\dfrac{1}{0.4}=2.5$；即便乘法器无限快，整机最多也只能快 2.5 倍。

题 2：Amdahl 定律反求可并行比例 p ⭐⭐⭐

题目：某科学计算程序部署到一台 16 核的并行计算机上，实测整机加速比为 8。假设程序的串行部分（1-p）在并行前后耗时不变，其余部分（p）被均匀划分到 16 个核上完美并行。求该程序的可并行比例 p。

考点：已知 N 和 Speedup，反求 p（Amdahl 多核版 $Speedup=\dfrac{1}{(1-p)+p/N}$）。

解答：

  1. 由公式 $8=\dfrac{1}{(1-p)+p/16}$，整理得：
    $$(1-p)+\frac{p}{16}=\frac{1}{8}=0.125$$
  2. 左边 $=1-p+\frac{p}{16}=1-\frac{15p}{16}$，故：
    $$1-\frac{15p}{16}=0.125\Rightarrow \frac{15p}{16}=0.875\Rightarrow p=\frac{0.875\times 16}{15}=\frac{14}{15}\approx 0.933$$
  3. 验证：$1-0.933=0.067$（串行 6.7%），$Speedup=\dfrac{1}{0.067+0.933/16}=\dfrac{1}{0.067+0.0583}\approx\dfrac{1}{0.1253}\approx 7.98$ ✓（与 8 一致，误差为舍入）。

要点/易错：若 $p$ 不够大，核数再多加速比也上不去；本题若要 $N=16$ 时达到理论最大加速比，需 $p\to 1$。

题 3：Amdahl 最大加速比（N→∞）与多 N 对比 ⭐⭐

题目：某程序中可并行部分占比 p=0.9。分别求处理器数 N=8、N=100、以及 N→∞（理论上限）时的加速比，并说明含义。

考点：$Speedup=\dfrac{1}{(1-p)+p/N}$ 与上限 $Speedup_{max}=\dfrac{1}{1-p}$。

解答：

  1. $N=8$：
    $$Speedup=\frac{1}{0.1+0.9/8}=\frac{1}{0.1+0.1125}=\frac{1}{0.2125}\approx 4.71$$
  2. $N=100$：
    $$Speedup=\frac{1}{0.1+0.9/100}=\frac{1}{0.1+0.009}=\frac{1}{0.109}\approx 9.17$$
  3. $N\to\infty$：
    $$Speedup_{max}=\frac{1}{1-0.9}=\frac{1}{0.1}=10$$
  4. 含义：从 N=8（4.71）到 N=100（9.17）核数增加 12.5 倍，加速比仅提升约 1.95 倍——体现了性能递减定律：并行部分加速收益随 N 增大急剧下降，上限被 10% 的串行部分锁定为 10。

要点/易错：上限由 $1-p$ 决定，与 N 无关；这是 Amdahl 定律的核心警告。

题 4：CPU 性能公式——两机比较 ⭐⭐⭐

题目：程序 P 在机器 A 上执行的指令条数 $IC_A=10^9$，平均 $CPI_A=1.5$，时钟频率 $f_A=2,\text{GHz}$。程序 P 编译后跑在机器 B 上，$IC_B=1.2\times 10^9$（指令更多），$CPI_B=1.0$，$f_B=3,\text{GHz}$。哪台机器更快？快几倍？

考点：$T_{CPU}=IC\times CPI\times T_{clk}=\dfrac{IC\times CPI}{f}$。

解答：

  1. 机器 A：
    $$T_A=\frac{IC_A\times CPI_A}{f_A}=\frac{10^9\times 1.5}{2\times 10^9}=0.75\ \text{秒}$$
  2. 机器 B：
    $$T_B=\frac{1.2\times 10^9\times 1.0}{3\times 10^9}=\frac{1.2\times 10^9}{3\times 10^9}=0.40\ \text{秒}$$
  3. 性能比（B 相对 A）：
    $$\frac{Perf_B}{Perf_A}=\frac{T_A}{T_B}=\frac{0.75}{0.40}=1.875$$

机器 B 更快，约为 A 的 1.875 倍。

要点/易错：虽然 B 的 IC 更大（1.2×），但它用更低的 CPI（1.0）和更高的频率（3 GHz）弥补了，最终更快。不可只看单一指标。

题 5：加权 CPI 计算 + 求所需时钟频率 ⭐⭐

题目：某机器四类指令的频率与 CPI 如下表：

指令类型 频率 $F_i$ $CPI_i$
ALU 50% 1
Load 20% 3
Store 10% 2
Branch 20% 2

程序共执行 $5\times 10^9$ 条指令。要求该程序的 CPU 执行时间不超过 2 秒。
（1）求该机器的平均 CPI；
（2）求所需最低时钟频率；
（3）若实际频率 $f=2,\text{GHz}$，实际执行时间是多少？

考点：$CPI=\sum CPI_i\times F_i$，反推 $f=\dfrac{IC\times CPI}{T_{CPU}}$。

解答：

  1. 加权 CPI：
    $$CPI=1\times 0.5+3\times 0.2+2\times 0.1+2\times 0.2=0.5+0.6+0.2+0.4=1.7$$
  2. 所需频率（要求 $T\le 2$ 秒）：
    $$f\ge\frac{IC\times CPI}{T_{CPU}}=\frac{5\times 10^9\times 1.7}{2}=4.25\times 10^9\ \text{Hz}=4.25\ \text{GHz}$$
  3. $f=2,\text{GHz}$ 时：
    $$T=\frac{5\times 10^9\times 1.7}{2\times 10^9}=4.25\ \text{秒}$$

要点/易错：Load 的 CPI=3 较高，虽然频率只有 20%，却贡献了 0.6 的 CPI（占 1.7 的 35%）——印证”加速常见情况/高代价情况”的设计思想。

题 6：MIPS 对比的陷阱 ⭐⭐

题目：机器 M1：$f_1=500,\text{MHz}$，某程序 $CPI_1=2.0$；机器 M2：$f_2=750,\text{MHz}$，同一程序 $CPI_2=3.0$。
（1）分别计算两机的 MIPS；
（2）计算同一程序（IC 相同）下两机的执行时间比，判断哪台更快；
（3）说明为什么单看 MIPS 会得出错误结论。

考点：$MIPS=\dfrac{f}{CPI\times 10^6}$，MIPS 与真实性能可能背离。

解答：

  1. MIPS：
    $$MIPS_1=\frac{500\times 10^6}{2.0\times 10^6}=250\ \text{MIPS}$$
    $$MIPS_2=\frac{750\times 10^6}{3.0\times 10^6}=250\ \text{MIPS}$$
    两机 MIPS 相同。
  2. 执行时间（设 $IC$ 相同）：
    $$T_1=IC\times 2.0/(500\times 10^6),\quad T_2=IC\times 3.0/(750\times 10^6)$$
    $$\frac{T_2}{T_1}=\frac{3.0/750\times 10^6}{2.0/500\times 10^6}=\frac{3.0\times 500}{2.0\times 750}=\frac{1500}{1500}=1.0$$
    执行时间相同，性能相同——本例 MIPS 与性能一致。
  3. 陷阱情形：若机器 M3 通过增加专用指令使某类指令条数 IC 减半，但 CPI 上升（如 2.0→2.5）。则 MIPS $=\dfrac{f}{CPI}$ 反而下降，看似变慢；但 $T=IC\times CPI/f$ 中 IC 减半可能让总时间减少，即真实性能提升而 MIPS 下降。MIPS 未考虑 IC 变化，因而可能误导。

要点/易错：MIPS 只反映 $f/CPI$，不含 IC，跨 ISA 或含编译优化时不可靠。这也是 SPEC 用几何平均比率的原因。

二、概念简答题

题 7：计算机体系结构 vs 计算机组成 vs 实现 ⭐⭐

题目：简述 ISA（体系结构）、微体系结构（组成）、实现三个层次的区别，并以”乘法指令”为例各举一个设计决策。

考点：三层抽象的边界划分。

解答：

  • ISA（Architecture）：程序员可见的接口，规定指令集、寻址方式、数据类型、寄存器、异常语义。
    • 乘法例：是否设置 MUL 指令（如 RISC 用移位加循环实现，无独立乘法指令）。
  • 微体系结构（Organization）：ISA 的逻辑实现，包括数据通路与控制流。
    • 乘法例：用加法器循环实现，还是用专用阵列乘法器（Booth 乘法器）。
  • 实现（Implementation）：物理实现，器件、电路、封装、电源、散热。
    • 乘法例：阵列乘法器用多少晶体管、布局走线、工作频率、功耗。

要点/易错：三层独立可变——同一 ISA 可有多种微架构（如 x86 的不同代微架构），同一微架构可有不同工艺实现。

题 8：ISA 的定义与优秀 ISA 的特征 ⭐

题目：什么是 ISA？它需要规定哪些主要内容？一个优秀 ISA 应具备哪些特征？

考点：ISA 的定位与设计准则。

解答：

  • 定义：ISA（Instruction Set Architecture，指令集架构）是软件与硬件之间的界面，规定机器可执行的指令集合、可见状态（寄存器/存储器）及语义。
  • 需规定的主要内容：存储器寻址、寻址方式、操作数类型与大小、操作种类、控制流指令、指令编码、异常与中断语义。
  • 优秀 ISA 的特征：
    1. Portability（可移植性）—— 可持续用于多代机器。
    2. Generality（通用性）—— 适用于多个应用领域。
    3. Convenient functionality（功能便利）—— 对上层提供方便的功能。
    4. Efficient implementation（实现高效）—— 可由下层高效实现。

要点/易错：IBM System/360 首次将 ISA 与实现分离，是软件可移植性的里程碑；现代 RISC（ARM、RISC-V）因实现高效、可移植而占据 99% 处理器市场。

题 9：Benchmark 的类型与几何平均 ⭐⭐

题目：（1）按预测精度从高到低列出 benchmark 的五种类型；（2）SPEC CPU 为什么用几何平均？几何平均相比算术平均有什么关键特性？

考点：benchmark 分类与性能综合评价方法。

解答：

  1. 五种类型（预测精度递减）：
    ① 真实程序（如编译器、数据库）→ ② 修改过的程序 → ③ 核心程序（Livermore Loops、LINPACK）→ ④ 小测试程序（toy，<100 行）→ ⑤ 合成测试程序（Whetstone、Dhrystone）。
  2. SPEC 用几何平均的原因与特性：
    • 性能比（ratio）取几何平均时，$GM(Ratio)=Ratio(GM)$，即几何平均的比率等于比率的几何平均。
    • 几何平均值与参考机器的选择无关，便于跨平台比较。
    • 相比算术平均，几何平均不会被单个极端值（如一个程序特别慢）过度放大，更能反映整体均衡性能。

$$GM=\sqrt[n]{\prod_{i=1}^{n} Ratio_i}$$

要点/易错：算术平均受参考机器或量纲影响，几何平均更适合无量纲的”性能比”指标。

三、公式速查

公式 含义
$T_{CPU}=IC\times CPI\times T_{clk}=\dfrac{IC\times CPI}{f}$ CPU 执行时间（Iron Law）
$CPI=\displaystyle\sum_i CPI_i\times F_i$ 加权平均 CPI
$T_{clk}=\dfrac{1}{f}$ 时钟周期与频率互逆
$Speedup=\dfrac{1}{(1-F)+F/S}$ Amdahl 定律（部分加速比 S）
$Speedup=\dfrac{1}{(1-p)+p/N}$ Amdahl 定律（多核并行版）
$Speedup_{max}=\dfrac{1}{1-F}=\dfrac{1}{1-p}$ 加速比上限（N→∞）
$MIPS=\dfrac{IC}{T\times 10^6}=\dfrac{f}{CPI\times 10^6}$ MIPS 指标（注意 IC 陷阱）
$Performance=\dfrac{1}{Execution\ Time}$ 相对性能定义
$GM=\sqrt[n]{\prod Ratio_i}$ 几何平均（SPEC 用）
$Power_{dyn}\propto C\times V^2\times f$ 动态功耗
