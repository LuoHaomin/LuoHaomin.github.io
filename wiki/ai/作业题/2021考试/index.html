2020~2021学年第二学期考试试卷

一、判断题（10分）

  1. 如果 (h_1) 和 (h_2) 是两个可采纳（admissible）启发式函数，那么在 A* 算法中，使用启发式函数 (h_3(n)=\max(h_1(n),h_2(n))) 一定比使用启发式函数 (h_4(n)=\min(h_1(n),h_2(n))) 更好。 （　）
  2. 对于任何决策树上的根节点，其信息增益（Information Gain）一定不比树中其他节点的信息增益少。 （　）
  3. 随着 k-NN 分类器中使用的 k 值从 1 逐渐增加到 n（即训练样本的总数），训练集上的分类精度将始终增加。 （　）
  4. K-Means 聚类保证收敛（即算法会终止）。 （　）
  5. 一个使用 quadratic kernel (K(x,y)=(1+x^\top y)^2) 的 SVM，可以正确分类这个数据集 ({(1,1),+}, (1,-1),-, (-1,1),-, (-1,-1),+})。 （　）

二、单项选择题（10分）

  1. 假设有一个状态空间，其中所有边（状态转移）的代价都是 1，同时我们没有启发式函数。我们想要使用节省空间的搜索算法（仅考虑边界（Fringe）在搜索期间存储的最大节点数），同时保证我们能找到最优解。在这种情况下，最好使用以下哪一种搜索方法？

（A）广度优先搜索（Breadth-First Search）

（B）深度优先搜索（Depth-First Search）

（C）迭代加深的深度优先搜索（Iterative-Deepening Search）

（D）一致代价搜索（Uniform-Cost Search）
2. 给定布尔随机变量 A、B 和 C，并且它们之间没有独立性或条件独立性假设，以下哪一项等于 (P(A,B,C))？

（A）(P(A|B)P(B|C)P(C|A))

（B）(P(C|A,B)P(A)P(B))

（C）(P(A,B|C)P©)

（D）(P(A|B)P(B|C)P©)
3. Naive Bayes 分类器做了以下哪项假设？

（A）所有属性都是独立的。

（B）给定输出标签，所有属性都是条件独立的。
4. 给定如下汉诺塔问题（从初始状态到目标状态，每次只能移动一个顶端的圆盘，并且任何时候大盘不能在小盘上面），有三个盘子重量从小到大分别是 1、2、3，每步行动的代价（cost）为盘子的重量乘以盘子移动的距离（第一个杯子与第三个杯子距离为 2，相邻杯子距离为 1）。下列定义中不显示可采纳（admissible）启发式函数的是？

（A）在第三个杆上的盘子数目。

（B）不在第三个杆上的盘子数目。

（C）不在第三个杆上的盘子重量。

（D）不在第三个杆上的盘子重量乘以它们与第三个杆子的距离。

（原题附有汉诺塔示意图，此处省略）

  1. 使用 K-Means 聚类算法将 7 个点聚类为 3 类。假设第一次迭代后，簇 C1、C2 和 C3 包含以下二维点：

C1 包含两个点：((0,6), (6,0))

C2 包含三个点：((2,2), (4,4), (6,6))

C3 包含两个点：((5,5), (7,7))

哪些中心点可以生成这三簇？

（A）C1: (3,3), C2: (4,4), C3: (6,6)

（B）C1: (3,3), C2: (6,6), C3: (12,12)

（C）C1: (0,0), C2: (48,48), C3: (35,35)

（D）以上都不对。

四、（12分）

考虑以下在扩展节点 A 和 B 后生成的搜索树，其中每个边上都标注了相应的代价（cost），每个节点标有相应的启发式函数 h 的值。对于无信息搜索（uninformed search），假设子项从左到右展开。当有多个节点并列选择时，按字母顺序选择。针对下列搜索算法给出下一个应该扩展的节点。

  1. 深度优先搜索（Depth-First Search）
  2. 一致代价搜索（Uniform-Cost Search）
  3. 贪心最优搜索（Greedy Best-First Search）
  4. A* 搜索

在下面的博弈树中，轮到 Max 决策。每个叶子结点的数值代表对相应状态的评估结果。

  2. 采用 alpha-beta 剪枝，列出所有被剪枝的叶子结点。

六、（14分）

将下列句子分别用一阶逻辑公式表达，并进行推理（保持不同句子中谓词一致）。

  1. 自然语言语句：

（1）所有的机器人都是聪明的。

（2）有些机器人是聪明的。

（3）Robbie 是一个机器人。

（4）所有的机器人都对它的主人友好。

（5）Bob 是 Robbie 的主人。

（6）有些拥有机器人的人是聪明的。
2. 采用归结方法（Resolution）证明“Robbie 对 Bob 友好”。
3. 基于以上知识库，能否证明“Bob 是聪明的”？如果成立，请给出证明过程；如果不成立，请解释为什么。

七、（16分）

考虑如下具有 4 个布尔型随机变量的贝叶斯网络（Bayesian network）。

A → C;A → D;B → D

  1. 计算 (P(\neg A, B, \neg C, D))。
  2. 判断 A 与 B 在给定 D 时，是否条件独立？
  3. 计算 (P(A|B,C,D))。
  4. 计算 (P(A|\neg D))。

八、（16分）支持向量机

  1. 已知正例点 (x_1 = (2,3)^\mathrm{T})，(x_2 = (3,3)^\mathrm{T})，负例点 (x_3 = (1,1)^\mathrm{T})，试求硬间隔支持向量机（Hard Margin SVM）的最大间隔分离超平面和分类决策函数，并在图上画出分离超平面，指出所有的支持向量。
  2. 现额外有一个点能被 SVM 正确分类且远离决策边界，如果将该点加入到训练集，SVM 的决策边界会受到影响吗？为什么？
  3. 现额外有一个点不能被当前的 SVM 正确分类且远离决策边界，如果将该点加入到训练集并将硬间隔支持向量机扩展为软间隔支持向量机（Soft Margin SVM），SVM 的决策边界会受到影响吗？为什么？
